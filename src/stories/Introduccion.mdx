# Trama

Trama es un design system multimarca. Una sola base de tokens y componentes sirve a dos productos:

- **Hilo:** inbox compartido de WhatsApp para equipos pequeños de servicio. Color añil, esquinas más redondeadas.
- **Ruta:** panel de reservas para operadores de tours en Costa Rica. Color atardecer, esquinas más rectas.

Usa los selectores **Marca** y **Modo** de la barra superior para ver cualquier componente en los cuatro temas.

## Cómo está construido

1. **Tokens en tres capas:** primitivos (valores crudos), luego marca (Hilo o Ruta) y al final semánticos (claro u oscuro). Los componentes solo usan tokens semánticos.
2. **Una sola fuente de verdad:** `tokens/trama-tokens.json` alimenta las variables de Figma y, con Style Dictionary, las variables CSS de este código.
3. **Mismos nombres en diseño y código:** `color/action/primary` en Figma es `var(--color-action-primary)` aquí.

## Accesibilidad

Todos los temas cumplen **WCAG 2.2 AA**: texto con contraste de al menos 4.5:1, bordes de controles y anillo de foco de al menos 3:1, área mínima de 24 px, el color nunca es la única señal y las animaciones se desactivan si la persona lo pide en su sistema. El panel **Accessibility** de cada historia corre pruebas automáticas con axe.

## Uso

```tsx
import { TramaTheme, Button } from 'trama-design-system';

<TramaTheme brand="ruta" mode="dark">
  <Button variant="primary" size="m">Nueva reserva</Button>
</TramaTheme>
```

`TramaTheme` aplica `data-brand` y `data-mode` en el mismo elemento, que es lo que necesitan los tokens para resolver la marca correcta.
